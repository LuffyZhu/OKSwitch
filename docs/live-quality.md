# 体育直播画质

咪咕赛事直播默认请求高清档（`rateType=3`）。播放时按 `+` 打开画质菜单，方向键可选择标清 540P（`rateType=2`）、高清 720P（`rateType=3`）或蓝光 1080P（`rateType=4`）；菜单不会暂停当前画面，按 `A` 后才请求所选画质并切换直播流。按 `B` 或再次按 `+` 关闭菜单。蓝光档可能需要对应的咪咕会员权益，实际分辨率以咪咕返回的视频流为准。原画 HDR 未接入。

电视频道及其他只提供固定直播地址的线路会显示“当前线路固定画质”，无法在播放器内降档。主界面的 `+` 不再用于关闭 OKSwitch；通过 Switch 的 HOME 菜单关闭软件。
